## 怎样记一条

1. 每条控制在几行：一句话结论、为什么/何时用、易错点、代码或项目链接。
2. 每个模块保留 5–12 条核心笔记；零散小知识合并，避免笔记本身变成另一个大仓库。
3. 模块页末尾放主动回忆题。复习时先遮住答案口述或写出，再查笔记补漏。
4. 新学到重要内容时，可以直接告诉导师“把这个记到模块 X 笔记”，由导师更新这里。

新模块开始时复制 [_template.md](_template.md)，命名为 module-NN-topic.md，并把链接补到本索引。
