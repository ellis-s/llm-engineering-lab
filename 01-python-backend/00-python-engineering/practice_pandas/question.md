# Pandas 综合实战题

共 7 题，难度均为中等。每题可独立完成，参考答案见同目录 [answer.md](answer.md)。

## 数据与统一约定

- [用户下单数据.csv](<files/用户下单数据.csv>)：GBK 编码，字段包括 `用户ID`、`用户出生日期`、`性别`、`婚姻状况`、`文化程度`、`下单时间`、`订单ID`、`交易金额`。
- [电商销售数据.xlsx](<files/电商销售数据.xlsx>)：包含 `销售数据`、`销售数据_清洗` 两个工作表，字段包括 `日期`、`订单号`、`区域`、`客户性别`、`客户年龄`、`商品品类`、`进货价格`、`实际售价`、`销售数`、`销售额`、`利润`。
- 从本 Markdown 所在目录运行代码。安装依赖：`pip install pandas openpyxl matplotlib`。不要覆盖原始数据文件。
- 除特别说明外，每行算一条**记录**，不是一个去重订单或用户；金额先用原始精度计算，最后展示时才四舍五入。订单号和用户 ID 当作标识符而非数值计算。
- 两个文件不一定描述相同订单，也没有现成的用户关联键。不能仅因为字段含义相似就把行当作同一笔交易。

## 题 1：销售数据质量检查与清洗

**数据源：** Excel 的 `销售数据_清洗` 工作表。

1. 读取数据，显示行列数、各列类型、各列缺失数，统计整行重复数及按 `订单号` 判断的重复数。
2. 去除完全重复行，保留第一次出现的记录；报告清洗前后记录数、销售额和利润的合计及差额。不要因订单号相同而直接删除内容不同的行。
3. 将日期转为日期类型；把 `区域` 按 `-` 分为 `大区`、`省份`、`城市`，清除各部分首尾空格；把带 `¥` 的进货价格转为数值列 `进货价格_数值`。
4. 将缺失的客户性别填为 `未知`、商品品类填为 `未知品类`；保留数值字段的缺失，不编造销量或年龄。按清洗后的客户性别统计记录数和销售额，并验证分组销售额合计与清洗后全表一致。

**考查：** 读 Excel、缺失与重复处理、字符串拆分、类型转换、分组校验。

## 题 2：订单消费画像与分箱

**数据源：** CSV 的全部记录。

1. 将出生日期、下单时间转为日期时间。参照课程使用 `2024 - 出生年份` 计算近似年龄，明确这不是截至某天的精确周岁。
2. 将年龄分为 `(0,30]`、`(30,40]`、`(40,50]`、`(50,100]`，检查是否有未分箱记录。按年龄段、性别统计记录数、去重用户数、交易金额合计和平均值。
3. 按单笔交易金额的四分位数做四组等频分箱，展示各组记录数、金额范围及平均金额；若分位点重复，允许减少分箱数并说明原因。
4. 计算单笔金额的 90% 分位数，筛选严格大于阈值的记录，输出记录数、占全部记录的比例和平均金额。说明高价值**订单记录**不等同于高价值用户。

**考查：** 日期、`cut`、`qcut`、分组聚合、分位数。

## 题 3：复购用户与用户级消费榜

**数据源：** CSV 的全部记录。

1. 检查 `订单ID` 的重复情况，列出所有重复 ID 的记录，比较整行重复与仅 ID 重复。假定目前无法判定这些不同记录是否应合并，后续一律保留。
2. 按 `用户ID` 统计下单记录数、总交易金额、平均单笔金额、首次和最近下单时间，并计算至少有 2 条记录的用户数及其占全部用户数的比例。
3. 先检查每个用户的 `性别`、`婚姻状况`、`文化程度` 是否分别一致；若不一致则提示并停止，不要任意挑选资料。用用户画像表和用户汇总表进行一对一合并。
4. 按总交易金额降序、用户 ID 升序输出前 10 名；再按用户的性别统计用户数、复购用户数和人均累计消费。解释这里的复购只是数据集内多条记录，不一定代表不同订单。

**考查：** 去重判断、用户粒度与记录粒度、`groupby`、`merge`、排序。

## 题 4：大区与品类经营分析及表格重塑

**数据源：** Excel 的 `销售数据` 工作表；不使用该表的进货价格进行成本计算。

1. 处理日期和区域，按 `大区`、`商品品类` 汇总记录数、销售数、销售额和利润，计算利润率：组内利润合计 ÷ 组内销售额合计 × 100%；销售额为 0 时利润率留空。
2. 在每个大区内按销售额降序、品类名称升序，输出销售额最高的 3 个品类。
3. 构造“大区 × 商品品类”的销售额透视表，缺失组合补 0；将透视结果通过 `melt` 还原为长表，校验长表销售额合计等于原始数据总销售额。
4. 按品类汇总销售额、利润，并计算各品类在全表销售额中的占比。解释利润率为什么应先汇总再相除，而不是直接平均每条记录的利润率。

**考查：** 字符串拆分、多个分组指标、排序、透视、`melt`、加权指标。

## 题 5：每日销售趋势与可视化

**数据源：** Excel 的 `销售数据` 工作表。

1. 按自然日汇总记录数、销售额、利润。用最早至最晚日期补齐自然日，无记录日三项填 0；按日期升序排列。
2. 计算销售额的 7 个**自然日**移动平均，要求窗口内满 7 天才显示结果。分别给出销售额最高的日期及其销售额、第一天有移动平均的日期和数值；若最高值并列，选择最早日期。
3. 按周一至周日汇总总记录数、总销售额、自然日数和日均销售额；以自然日数为分母，包括补齐的零销售日。
4. 绘制每日销售额和 7 日均值折线，保存到当前目录 `每日销售趋势.png`，图表标明日期、金额和图例。说明中文字体缺失时可按操作系统配置字体。

**考查：** 时间序列、补齐日期、滚动窗口、分组统计、Matplotlib。

## 题 6：两个工作表的订单对账

**数据源：** Excel 的 `销售数据` 和 `销售数据_清洗` 工作表。

1. 以字符串读取两表订单号。分别检查整行重复和订单号重复；对 `销售数据_清洗` 只删除完全重复行，检查两表订单号均非空且唯一，若不满足则停止。
2. 按订单号外连接，使用 `indicator` 和 `validate` 检查两表订单号的匹配情况。注意不能按行位置拼接。
3. 对匹配记录将两表的 `进货价格` 去除 `¥` 后转为数值，统计两表价格不同的记录数；分别检查每表中 `利润 = (实际售价 - 进货价格) × 销售数` 的可校验记录数和不相等记录数。销售数等必要字段缺失时计为不可校验，不视为匹配或不匹配。
4. 输出一个价格不同的订单号及两表对应价格、售价、销量和利润，说明不能仅凭工作表名称认定数据可靠；价格差异需要业务确认，不能自动认定某表一定正确。

**考查：** 重复键检查、外连接、类型转换、缺失值和业务公式校验。

## 题 7：跨数据集的关联可行性与报表

**数据源：** CSV 的全部记录和 Excel 的 `销售数据` 工作表。

1. 将 CSV 的 `订单ID` 和 Excel 的 `订单号` 作为字符串，分别取非空唯一键，以一对一外连接统计只在 CSV、只在 Excel、两边都有的键数。
2. 各自按性别汇总记录数、金额合计和记录平均金额；CSV 用 `性别`、`交易金额`，Excel 用 `客户性别`、`销售额`。统一列名并添加数据源列，再纵向拼接，保留两数据集各自的统计口径。
3. 将键匹配统计和拼接后的性别汇总写入当前目录 `综合分析报表.xlsx` 的 `键匹配`、`性别汇总` 两个工作表，不导出 DataFrame 索引。运行会覆盖同名报表。
4. 根据键匹配结果和字段、日期范围，解释能否把两表视为同一批订单并据此分析用户的商品品类；为什么也不能把两表金额简单相加为一个业务总额？

**考查：** 标识符、外连接、`concat`、分组、Excel 多工作表导出及分析边界。
